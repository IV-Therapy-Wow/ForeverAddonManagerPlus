ForeverAddonManagerPlus

Different addon setups for different parts of the game.

I made this because I wanted my addons to change with the kind of content I was playing, without rebuilding the list every time. ForeverAddonManagerPlus keeps profiles for each location type and can switch to the right one as you move around Azeroth.

Profiles for every location

Keep separate addon setups for World, City, Instance, Raid, Battleground, Arena, Tram, Scenario, and Other. The addon detects the type of area you're in and selects that profile. City detection is limited to the major auction-house hubs, so inns and resting areas in smaller towns such as Gadgetzan won't switch you to the City profile. The tab you're viewing has a green outline and bright white text, so it's clear which page is selected. When it matches the area you're in, a round green marker and the words THIS RULESET IS ACTIVE identify the active ruleset. The original nebula background is unchanged.

Separate profiles for class and role

Choose DPS, Healer, Tank, or Support for your class and keep a different set of location profiles for each role. Role selection is manual, so you decide which setup you want to use.

Profiles that keep their addon settings

Make extra named profile copies for different activities. You can also copy the active settings from another location tab instead of setting up the same addon list again. The manager asks before copying. The settings go into the current tab's draft, so you can review them and click Save Page when you're happy with the result.

Missing addons stay in your profiles

Addon choices are saved by folder name. If you remove an addon, its profile entries stay in the registry and are there when you install it again. Missing addons are hidden from the list by default; turn on Show missing addons when you want to see them. Refreshing the list won't clear those saved choices.

Start from Blizzard's AddOns settings

On a fresh installation, the default location profiles are filled using the enabled and disabled choices in Blizzard's AddOns window. The first-use reminder stays until you save your setup. After that, your saved profiles take over and later scans won't replace your choices.

The Synchronize from Blizzard Settings button copies Blizzard's current on/off choices into the selected tab, or into the active profile on all nine location tabs in the current profile set. The Save Page button is enabled after updating the current tab. Updating all tabs asks for a second confirmation because it replaces more than one profile.

Minimap button and settings

The minimap button can be moved around the minimap and adjusts to different shapes. It fades when you're not using it. From Settings, choose whether it appears and what information is shown in its tooltip, including your selected class and role, your current location type, and an optional list of addon states.

The addon list keeps two things separate: the checkbox is the setting saved in your selected profile, while the round status marker shows the addon's current state. Green means it is enabled and loaded; red means it is disabled or not running; grey in the main list means it is not installed. The tooltip keeps each addon's own name colours and puts the status dot beside the name. The class icon, role icon, and role text are larger and easier to read. The list scrolls smoothly and has up/down buttons beside the scrollbar.

Getting started

  1. Put the ForeverAddonManagerPlus folder in your Interface/AddOns folder.
  2. Enable ForeverAddonManagerPlus in Blizzard's AddOns list at character select.
  3. Log in and type /famp, or open it with the minimap button.
  4. Review the default profiles, which start from the current Blizzard AddOns settings on a fresh install.
  5. Save your setup. The first-use reminder won't appear again once you've saved.

The Toggle Addons button opens Blizzard's AddOns window. If you have unsaved changes, the manager lets you cancel, discard them, or save before switching windows. The Command List button shows the slash commands; click one to select it for copying.
